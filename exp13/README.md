## Objective

The objective of this project is to create a simple backend API using Flask to perform CRUD (Create, Read, Update, Delete) operations on student data stored in a MySQL database.

## Tools Used

Python (Flask), MySQL, Postman

## What I Did

* Created a database and table in MySQL
* Built a Flask server
* Implemented CRUD APIs for student data
* Tested all APIs using Postman
